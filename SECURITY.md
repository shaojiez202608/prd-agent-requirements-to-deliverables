# Security policy

## Reporting a vulnerability

Do not open a public issue for security problems. Use the private vulnerability reporting feature of the platform
that hosts this repository, or the private contact channel listed by the maintainers there. Include the affected
file or command, steps to reproduce and the impact you expect. You will get an acknowledgement and a follow-up when
a fix or decision is available.

## Scope

This is a prototype for non-production use. Known risks and design limits are listed in SECURITY-NOTES.md and
THREAT_MODEL.md.
